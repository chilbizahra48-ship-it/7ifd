# 7ifd (حِفظ) - منصة تعلم اللغات والتكرار المتباعد (Spaced Repetition)

> منصة عصرية متكاملة لتعلم وإتقان اللغات الأجنبية بنظام التكرار المتباعد الذكي (SM-2 SRS)، مع دعم 11 لغة عالمية، 8 مجالات حيوية، وتصنيف المستويات الأوروبية المرجعية (CEFR من A1 إلى C2).

---

## 🌟 الميزات الرئيسية (Key Highlights)

- ⚡ **العمل بدون إنترنت أولاً (Offline-First Architecture)**:
  - يعمل الموقع والتطبيق بشكل مستقل تماماً دون الحاجة لأي مفتاح API أو اشتراكات مدفوعة.
  - تخزين محلي شامل وسريع عبر متصفح الهاتف أو الكمبيوتر باستخدام **IndexedDB**.
  - حزم بيانات متكاملة مسبقاً تضم أكثر من 2,400 بطاقة تعليمية وجمل واقعية عبر كافة اللغات الـ 11.
- ☁️ **المزامنة السحابية والحسابات (Firebase Firestore & Auth)**:
  - دعم اختياري لتسجيل الدخول وإنشاء الحسابات ومزامنة التقدم بين الأجهزة عبر Firebase.
  - يعمل كـ Guest محلياً بالكامل في حال عدم الاتصال أو عدم تسجيل الدخول.
- 📱 **تطبيق ويب تقدمي متكامل (PWA)**:
  - قابل للتثبيت كبرنامج كامل على هواتف Android و iPhone وأجهزة الحاسوب بدون متجر تطبيقات.
  - دعم الاستيراد والتصدير عبر ملفات CSV و JSON ومشاركة الملفات مباشرة في الهاتف.
- 🤖 **هيكلية ذكاء اصطناعي مرنة ومفصولة (Modular AI Adapter)**:
  - تم تعطيل الاعتماد الإجباري على Google Gemini API لضمان استقلالية المشروع وخلوه من تكاليف الدفع.
  - تم تنظيم كود الذكاء الاصطناعي في مجلد مستقل (`src/lib/ai/`) لتسهيل إعادة تفعيله في ثوانٍ متى رغبت بذلك بمجرد تغيير متغير واحد.

## 🗂️ هيكل البيانات المدمجة (8 مجالات و 11 لغة)

تحتوي المنصة في قسم التصفح (`ExploreScreen`) على 8 مجالات أساسية منظمة:
1. **الأساسيات اليومية (Everyday Essentials)**
2. **التحيات والتواصل الاجتماعي (Greetings & Social Interaction)**
3. **السفر والتنقل (Travel & Transportation)**
4. **الطعام والتسوق (Food & Shopping)**
5. **المنزل والمدينة (Home & City)**
6. **العمل والأعمال (Work & Business)**
7. **الصحة والطوارئ (Health & Emergencies)**
8. **الثقافة والترفيه (Culture & Entertainment)**

**اللغات المدعومة بالكامل:**
العربية (AR)، الإنجليزية (EN)، الفرنسية (FR)، الإسبانية (ES)، الألمانية (DE)، البرتغالية (PT)، الصينية المبسطة (zh-CN)، اليابانية (JA)، الكورية (KO)، التايلاندية (TH)، والهندية (HI).

## 🚀 التشغيل والتطوير المحلي (Quick Start)

```bash
# 1. تثبيت الحزم
npm install

# 2. تشغيل خادم التطوير المحلي
npm run dev

# 3. بناء المشروع للإنتاج (Production Build)
npm run build
```

## 🌐 النشر على GitHub Pages

تم ضبط إعدادات Vite لدعم النشر على GitHub Pages في المسار الفرعي `/7ifd/` تلقائياً عند تنفيذ `npm run build`:
- المسار الأساسي في التطوير المحلي: `/`
- المسار الأساسي في البناء النهائي: `/7ifd/` (أو تخصيصه عبر `VITE_BASE_PATH`)

لرفع المشروع على GitHub:
```bash
git add .
git commit -m "feat: offline-first 7ifd language platform ready for deployment"
git branch -M main
git remote add origin https://github.com/<YOUR_USERNAME>/7ifd.git
git push -u origin main
```

## 🔌 كيفية تفعيل ميزات الذكاء الاصطناعي مستقبلاً (اختياري)

إذا أردت لاحقاً إعادة تفعيل Gemini API لتوليد البطاقات تلقائياً:
1. افتح الملف `src/lib/ai/gemini.ts`.
2. غيّر قيمة `ENABLE_AI_FEATURES` إلى `true` (أو اضبط `VITE_ENABLE_AI="true"` في ملف `.env`).
3. أضف مفتاحك في `VITE_GEMINI_API_KEY` أو `GEMINI_API_KEY`.
4. سيبدأ النظام تلقائياً باستدعاء نموذج `gemini-2.5-flash` دون الحاجة لأي تعديلات إضافية في واجهات المستخدم.
